# ShieldKit V2 Direct assurance pack

This is a claim-to-evidence definition for the V2 Direct subject frozen at
ShieldKit SDK commit `2ba14fd7d1d5d0acdd49b97ea3ee77b8ab0ea854`, tree
`6023d6504e2958efced6906b34f523eebc5147ce`. It is not evidence, a release
record, a beta promotion, or authorization to use mainnet.

The pack covers P01-P15, the A/B/C/D phase gates, and Q01-Q09. Every mandatory
obligation requires non-synthetic, final-artifact-bound evidence. The current
single-contributor beta ceremony, ignored local PF10 evidence, public Chipnet
exploratory transactions, and old V1/PF7 artifacts are deliberately excluded as
promotable evidence.

The mandatory hard ceilings are complete-transaction bytes <= 100000, every
unlocking bytecode <= 10000 bytes, and every VM resource <= 100 percent. The
history requirement is one continuous 100000-action history, not an aggregate
of smaller histories.

Setup trust is a separate reported axis. A multiparty ceremony is an optional
stronger trust profile, while an honestly disclosed single-contributor setup
does not establish participant independence. Independent audits remain mandatory
for release in either case.
