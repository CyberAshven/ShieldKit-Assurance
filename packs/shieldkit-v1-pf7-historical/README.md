# ShieldKit V1/PF7 historical pack

This is a read-only historical boundary pack for the V1 PF7 subject observed at
ShieldKit SDK revision `2ba14fd7d1d5d0acdd49b97ea3ee77b8ab0ea854`.

It records the actual V1 identifiers and byte/topology boundaries: `SHST` (80
bytes), `SCAR` (752 bytes), seven PF7 roles, preparation plus ten-input
settlement, and the historical Chipnet playground. It deliberately contains no
qualification obligation and no promotable evidence path.

The pack is useful only to prevent a false migration: no V1 profile, artifact,
state, packet, setup, instance, or chain history may be relabeled as V2 Direct.
The listed legacy playground is not a V2 fallback or V2 qualification result.
